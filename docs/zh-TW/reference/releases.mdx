到 [GitHub Releases](https://github.com/zeabur-oss/identity/releases) 下載 Zeabur Identity，先驗證簽章與 checksum 再執行。Zeabur Identity 在 alpha 階段的發行版本皆標記為預先發行版。

## 檔案與平台

| 平台 | CLI 壓縮檔 | 容器映像檔 |
|---|---|---|
| Linux amd64 / x86_64 | `zeabur-identityctl-v<VERSION>-linux-amd64.tar.gz` | `ghcr.io/zeabur-oss/identity:v<VERSION>` |
| Linux arm64 / aarch64 | `zeabur-identityctl-v<VERSION>-linux-arm64.tar.gz` | 使用相同的映像檔標籤，Docker 會選擇你的架構 |

CLI 與伺服器皆採用靜態連結。macOS、Windows 或其他架構需要從原始碼建置 CLI。

每個發行版本都包含 checksum、簽章與 SBOM。SBOM 列出發行檔包含的相依套件，供下載的 SBOM 檔名以 `.cdx.json` 結尾。

## 下載並驗證

你需要 GitHub CLI（`gh`）、`cosign` `3.x` 與 GNU `sha256sum`。拉取映像檔還需要 Docker。除了 Docker，這些命令列工具都可在儲存庫的 `nix develop` shell 中使用。

<Steps>

<Step>

### 選擇版本與架構並下載

設定發行版本與架構，再下載該版本的檔案：

```sh
version=v0.1.0
arch=arm64 # use amd64 for x86_64
identity="https://github.com/zeabur-oss/identity/.github/workflows/release.yml@refs/tags/$version"
gh release download "$version" --repo zeabur-oss/identity --dir downloaded
```

</Step>

<Step>

### 驗證簽章與 checksum

先驗證 `SHA256SUMS` 的簽章，再用它檢查下載的檔案。`identity` 將簽章連結到 Zeabur Identity 的發行工作流程與你選擇的版本。

```sh
(
  set -e
  cd downloaded
  cosign verify-blob --bundle SHA256SUMS.sigstore.json \
    --certificate-identity "$identity" \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS
  sha256sum --check --strict SHA256SUMS
)
```

</Step>

<Step>

### 解壓縮並執行 CLI

兩項檢查都通過後，再解壓縮並試用 CLI：

```sh
tar -xzf "downloaded/zeabur-identityctl-$version-linux-$arch.tar.gz"
./zeabur-identityctl --help
```

</Step>

<Step>

### 驗證並拉取容器映像檔

從已通過檢查的 `image-digests.txt` 讀取映像檔 digest。digest 可識別映像檔的確切位元組內容。

```sh
image=$(awk '$1 == "index" {print $2}' downloaded/image-digests.txt)
cosign verify --certificate-identity "$identity" \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com "$image"
cosign verify-attestation --type cyclonedx --certificate-identity "$identity" \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com "$image"
docker pull --platform "linux/$arch" "$image"
```

映像檔與各平台版本都有簽章，並附上伺服器的 SBOM。已簽章的 checksum 也涵蓋 CLI 壓縮檔、供下載的 SBOM、映像檔 digest 與 `provenance.json`。`provenance.json` 記錄原始碼提交與建置執行紀錄。

</Step>

</Steps>
