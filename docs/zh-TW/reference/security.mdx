發現安全性弱點時，使用這個儲存庫的 GitHub **Report a vulnerability** 私下回報。不要為安全性問題建立公開 issue。

## 私下回報弱點

在這個儲存庫的 GitHub 頁面選擇 **Report a vulnerability**，使用 GitHub 的私密弱點回報功能提交問題。

## Alpha 支援範圍

Zeabur Identity `v0.1.0` 是 alpha 版本，供你在可隨時丟棄的自管叢集上評估使用。

- 只有最新發布的 alpha 版本提供安全修補。
- 安全修補隨新版本發布，舊版 alpha 不提供回溯修補。
- 不保證回應或修補時效。
- 安全修補發布後，請升級到最新 alpha 版本。

## 升級前的準備

Alpha 版本之間容許破壞性變更，範圍包含 Kubernetes 資源。專案不保證結構描述遷移、升級或回復到舊版。

保留獨立的叢集管理員憑證，並備妥經過還原測試的備份：

- 依照[保留不經過 Zeabur Identity 的入口](../operations/emergency-access.mdx)，保留獨立的管理入口。
- 依照[備份與還原](../operations/backup-restore.mdx)，準備並測試備份。
